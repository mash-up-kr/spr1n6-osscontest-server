# Security policy

## Reporting a vulnerability

Do not report security vulnerabilities in public issues. A public issue is visible to anyone before the fix is ready.

Report it privately through [Report a vulnerability in the Security tab](https://github.com/mash-up-kr/spr1n6-osscontest-server/security/advisories/new). Only maintainers can see the report.

Please include:

- The affected feature or API
- Steps to reproduce
- The expected impact (data exposure, permission bypass, etc.)

## Supported versions

Only the latest code on the `main` branch receives security fixes.
